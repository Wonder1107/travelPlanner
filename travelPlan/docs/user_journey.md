# 用户旅程（MVP）

## 阶段 1：准备（Onboarding）
- 用户输入城市、天数、预算、偏好与旅行笔记。
- 系统在 30 秒内生成初始行程。

## 阶段 2：执行（Trip）
- 用户查看时间轴与当前活动状态（拥挤度、排队时间、票量）。
- 遇到变化时，系统给出高价值替代建议。

## 阶段 3：调整（Replan）
- 输入事件（下雨、拥堵、疲劳）。
- MonitorAgent 判断是否触发。
- ReplanAgent 替换活动并说明原因与行动建议。

## 阶段 4：复盘（Console）
- 用户或面试官在控制台查看：
  - 检索候选点
  - 触发阈值判定
  - 替代方案路径估算
  - 变更结果
