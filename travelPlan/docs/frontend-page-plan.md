# 动态智能行程引擎 - 前端页面规划（MVP）

## 技能使用说明
- 使用技能：`figma`
- 原因：该技能用于设计驱动的前端规划与原型流程；当前未提供 Figma URL/Node，按技能 fallback 产出低保真页面原型与实现导向文档。

## 产品目标与前端范围
- 目标：让用户感知到“会实时变聪明”的 AI 旅行伴侣，而不是一次性行程生成器。
- MVP 场景：国内大城市周末 2-3 天游。
- 前端范围：
  - Onboarding 对话收集偏好并创建行程
  - 行程页展示时间轴与动态重规划提醒
  - Agent 控制台展示工具调用与决策理由

## 信息架构（IA）
- `/`：Onboarding + 创建行程
- `/trip/[id]`：行程执行页（时间轴、状态、动态建议）
- `/console`：Agent 控制台（日志、事件模拟、重规划结果）

## 页面规划

### 1) `/` Onboarding（核心入口）
**页面目标**
- 在 2-3 分钟内完成偏好采集并生成首版行程。

**关键模块**
- 顶部价值说明：突出“实时调整而非静态计划”
- 对话区：多轮问题（偏好、预算、节奏、避雷）
- 辅助输入区：小红书笔记/图片链接文本提取
- 快速选择 Chips：`museum`/`coffee`/`nightwalk`
- 生成按钮：创建行程并跳转 `/trip/[id]`

**关键状态**
- 空态：引导示例提问
- 生成中：骨架屏 + “正在检索 POI / 构建路线”
- 错误态：提示重试并保留输入

### 2) `/trip/[id]` 行程执行页（价值主舞台）
**页面目标**
- 让用户看见“动态重规划”在真实行程中持续生效。

**关键模块**
- 行程时间轴：按 Day 分组（上午/下午/晚间）
- 当前卡片：当前活动、排队时长、天气、路程
- 动态建议条：高优先级提醒与替代方案
- 动作区：`预约` `导航` `替换`（MVP 为 Mock）
- 用户状态快捷键：`我累了` `我饿了` `想室内`

**关键状态**
- 正常执行：按计划推进
- 触发重规划：弹出建议卡（原因 + 替代方案 + 影响）
- 已应用建议：时间轴高亮更新项

### 3) `/console` Agent 控制台（技术展示页）
**页面目标**
- 展示 RAG、Prompt、Agent 工具调用链，支持面试讲解。

**关键模块**
- Agent Trace：Planner / Monitor / Replanner 时间线
- Tool Logs：`search_poi_rag` `route_time` `weather_lookup`
- Prompt 摘要：系统提示词版本与结构化输出片段
- 事件模拟器：天气、拥挤、疲劳一键触发
- 结果对比：变更前后行程差异（diff）

## 全局组件与设计约束
- 顶栏：城市、天数、预算与“智能状态”标签
- 卡片体系：`ActivityCard`、`AlertCard`、`AgentLogCard`
- 可视化元素：拥挤度条、天气徽章、预算进度
- 响应式：移动端单栏；桌面端双栏（时间轴 + 建议区）

## 前端与 API 对接点
- `POST /api/trips`：提交 onboarding 信息并创建首版行程
- `GET /api/trips/{trip_id}`：拉取当前行程
- `POST /api/trips/{trip_id}/events`：提交实时事件并触发重规划
- `GET /api/trips/{trip_id}/logs`：控制台读取 Agent 日志

- 先演示 `/` 生成行程（RAG + Prompt）
